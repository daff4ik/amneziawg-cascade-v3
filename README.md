# 🚀 AmneziaWG Cascade v3 — каскадный VPN + веб-панель с сервисами

> **v3 — отдельная ветка развития проекта.** Стабильная версия v2 остаётся в репозитории [amneziawg-cascade-v2](https://github.com/daff4ik/amneziawg-cascade-v2) без изменений.

Каскадный VPN на AmneziaWG 3.1 с обфускацией: клиенты → SERVER-A (РФ) → туннель → SERVER-B (за рубежом) → интернет. `deploy.sh` сразу разворачивает весь каскад, а веб-панель на SERVER-A добавляет сервисы в один клик: собственный DNS с блокировкой рекламы и прокси для Telegram.

## 🆕 Что нового в v3

*   **deploy.sh = всегда каскад** на AmneziaWG 3.1 (как проверенная v2): туннель awg0 между серверами, клиентский awg1, Fail2Ban на обоих серверах, бэкапы.
*   **Вкладка «🧩 Протоколы» в веб-панели:**
    *   **AmneziaWG 3.1** — статус основного протокола + кнопка «⬆ Проверить обновления» (обновляет пакеты из PPA разработчиков на обоих серверах);
    *   **Amnezia DNS (unbound)** — свой резолвер без логов + **блокировка рекламы** (список oisd, ~190 тыс. доменов, обновляется еженедельно);
    *   **MTProxy (mtg v2)** — прокси для Telegram, ссылка `tg://proxy`;
    *   **Telemt** — прокси для Telegram на Rust с эмуляцией TLS (маскировка под HTTPS-домен).
*   **Вкладка «🌐 Серверы»:** замена SERVER-B из браузера, если его забанили по IP — панель сама заливает на новый сервер всё необходимое и переключает туннель «бесшовно» (конфиги клиентов не меняются).
*   **Бэкап SERVER-A:** ежедневно по cron + **автоматически после каждого изменения** (создание/удаление клиента, установка/удаление протокола) + вручную кнопкой в панели. Архив можно **скачать из панели**, копия хранится на SERVER-B, опционально — выгрузка в облако (Google Drive и др.) через rclone.

Наследовано из v2: IPv6 в туннеле (ULA + NAT66), Telegram-уведомления из панели, Stealth-режим (панель за сайтом-заглушкой на домене), отказоустойчивая установка через зеркала.

## 🏗 Архитектура

```text
┌────────┐      ┌─────────────────┐      ┌──────────────────┐      ┌──────────┐
│ Client │ ───► │  SERVER-A (RU)  │ ───► │  SERVER-B (DE)   │ ───► │ Internet │
│ (Amnz) │      │  Web-Panel      │      │  (Выходной узел) │      │          │
└────────┘ UDP  │  awg1 → awg0    │ UDP  │  awg0 → NAT      │      └──────────┘
          :585  └─────────────────┘ :8443└──────────────────┘
```

## 🚀 Установка (Быстрый старт)

На чистом **SERVER-A** (от `root`, Ubuntu 22.04 / 24.04 / Debian 12):

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh -o /tmp/deploy.sh >/dev/null; cat /tmp/deploy.sh)"
```

Скрипт интерактивно запросит:
1. IP-адрес SERVER-B и его SSH-пароль (используется единоразово, дальше — SSH-ключ).
2. Домен для Endpoint в клиентских конфигах (Enter = IP сервера A).
3. Разрешение на установку веб-панели и Fail2Ban.
4. Если на серверах есть IPv6 — предложит включить IPv6 в туннеле.
5. Если Endpoint — домен — предложит сразу спрятать панель в Stealth-режим.

После установки веб-панель: `https://<IP SERVER-A>:8000` (или за доменом, если включён Stealth).

> 💡 Для работы с сервером по SSH удобен MobaXterm: помимо терминала в нём есть SFTP-панель слева — ей можно скачать бэкап из `/root/amnezia-backups` или залить свою заглушку в `/var/www/stealth` простым перетаскиванием.

## 🧩 Протоколы и сервисы (вкладка «Протоколы»)

| Протокол | Порт по умолчанию | Ссылка для клиента |
|---|---|---|
| AmneziaWG 3.1 (основной) | 585/udp | `.conf` + `vpn://` (вкладка «Клиенты») |
| Amnezia DNS (unbound) | 53 (только внутри VPN) | DNS `10.8.0.1` для клиентов |
| MTProxy (Telegram, mtg v2) | 8444/tcp | `tg://proxy?...` |
| Telemt (Telegram, TLS-маскировка) | 8445/tcp | `tg://proxy?...` (ee-секрет) |

**Amnezia DNS** — собственный рекурсивный резолвер без логов: история запросов клиентов не уходит третьим сторонам. Кнопка «🔀 Клиентам — этот DNS» переключает всех клиентов AmneziaWG на него (обратно — «↩️ Вернуть Cloudflare»); клиенты заново импортируют конфиг/vpn:// ссылку.

**Блокировка рекламы:** кнопка «🚫 Реклама» на карточке Amnezia DNS. Рекламные и трекерные домены (список oisd big) получают NXDOMAIN на уровне резолвера — реклама отрезается для всех клиентов сразу, включая мобильные приложения. Список обновляется еженедельно по cron; вручную: `sudo amnezia-proto-amnezia-dns.sh adblock-update`. Изредка ломаются ссылки из рекламных рассылок — тогда блокировку можно выключить той же кнопкой.

**MTProxy vs Telemt:** оба дают прокси для Telegram. mtg легче и проще; Telemt эмулирует настоящий TLS выбранного домена (дольше живёт при активном противодействии). Можно держать оба на разных портах.

То же самое из консоли SERVER-A:
```bash
sudo amnezia-proto-amnezia-dns.sh install   # install | remove | status
sudo amnezia-proto-mtproxy.sh install       # install | remove | restart | status
sudo amnezia-proto-telemt.sh install        # install | remove | restart | status
```
Необязательные параметры — через окружение: `MTG_PORT`, `MTG_DOMAIN`, `TELEMT_PORT`, `TELEMT_DOMAIN`, `ENDPOINT_HOST`. Маскировочный домен можно задать и прямо в панели при установке MTProxy/Telemt (поле над кнопкой «Установить»). Учтите: секрет зашивает домен внутрь ссылки — при смене домена переустановите протокол и раздайте клиентам новую ссылку.

Если прокси периодически «отваливается», а `journalctl -u mtg` показывает `cannot dial to the fronting domain` — у хостера перебои с DNS. Привяжите маскировочный домен к IP: `echo "142.251.154.119 www.google.com" | sudo tee -a /etc/hosts && sudo systemctl restart mtg`.

## ⬆ Обновление AmneziaWG до новой версии

Когда разработчики Amnezia выпускают новую версию протокола:

* **Из панели:** вкладка «Протоколы» → карточка AmneziaWG → «⬆ Проверить обновления».
* **Из консоли:** `sudo amnezia-update-awg.sh`

Обновляются пакеты на обоих серверах, интерфейсы перезапускаются (клиенты переподключаются сами). Конфиги и клиенты не затрагиваются.

## 🌐 Замена SERVER-B при блокировке по IP

* **Из панели:** вкладка «Серверы» → добавить новый VPS (IP, SSH-порт, логин, пароль — пароль не сохраняется) → «Переключить». Панель сама установит AmneziaWG на новый сервер, перенесёт ключи и конфиг туннеля и переключит маршрутизацию. Клиенты ничего не замечают.
* **Из консоли:** `sudo amnezia-restore-b.sh`

## 💾 Бэкап и восстановление SERVER-A

**Когда делается бэкап:** ежедневно в 04:17 (cron) + автоматически после создания/удаления клиента и установки/удаления протокола + вручную кнопкой «Создать бэкап сейчас» (вкладка «Серверы»). Хранятся последние 7 копий.

**Где хранится:**
1. локально на SERVER-A (`/root/amnezia-backups`);
2. копия на SERVER-B (по SSH-ключу, автоматически);
3. у вас на компьютере — кнопка «⬇ Скачать» в панели или SFTP в MobaXterm;
4. опционально в облаке — `sudo amnezia-backup-cloud.sh` настроит выгрузку через rclone (Google Drive, S3, Яндекс.Диск и др.; для Google Drive мастер попросит авторизоваться с вашего компьютера командой `rclone authorize "drive"`).

**Восстановление на новом сервере A:**
```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh)" -- --restore
```
Скрипт заберёт последний бэкап с живого SERVER-B и поднимет всё сам — конфиги клиентов менять не нужно; если Endpoint — домен, обновите его A-запись. Если SERVER-B тоже потерян, но у вас есть скачанный архив — разверните его содержимое в корень нового сервера (`tar -xzf amnezia-backup-*.tar.gz -C /`) и выполните `deploy.sh --update`.

## 🛡️ Защита веб-панели (Stealth-режим)

Панель прячется за сайтом-заглушкой (Nginx) на вашем домене: по IP и по корню домена открывается нейтральная страница, панель — только по секретному пути `https://домен/кодовое_слово/`. SSL выпускается через Let's Encrypt автоматически.

* **При установке:** если Endpoint — домен, установщик предложит включить Stealth сразу и спросит кодовое слово.
* **Позже:** `sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/stealth-setup.sh)"` или `deploy.sh --update`.
* **Свой сайт:** залейте свой `index.html` в `/var/www/stealth` — перенастройка не потребуется.
* **Аварийный доступ:** `sudo amnezia-panel-access.sh on|off` — временно открыть/закрыть панель по IP:8000.

## 🤖 Telegram-бот управления

Если настроены Telegram-уведомления (вкладка «🔔 Уведомления» в панели), тот же бот умеет выполнять команды — из лички или из группового чата. Напишите боту `/menu` — появится **кнопочное меню** (статус, клиенты, добавление/удаление, рестарт, бэкап), а если включён Stealth на домене — в меню и в кнопке у поля ввода появляется **«🖥 Панель (Mini App)»**: веб-панель открывается прямо внутри Telegram.

Команды (дублируют кнопки):

| Команда | Что делает |
|---|---|
| `/status` | состояние туннеля awg0/awg1, handshake, число клиентов, uptime |
| `/clients` | список клиентов и трафик |
| `/add <имя>` | создать клиента (пришлёт `.conf` файлом + `vpn://` ссылку) |
| `/del <имя>` | удалить клиента |
| `/restart` | перезапуск туннелей awg0+awg1 |
| `/restart_panel` | перезапуск веб-панели |
| `/backup` | создать бэкап сейчас |
| `/reboot` | перезагрузка сервера (с подтверждением `/reboot ДА`) |

* Бот отвечает только чатам из `/etc/amnezia-notify.conf`: основному `TELEGRAM_CHAT_ID` плюс необязательному списку `TELEGRAM_BOT_ALLOWED="id1,id2"` (можно дописать туда id группы). Чужие сообщения игнорируются.
* Для группового чата: добавьте бота в группу, у @BotFather отключите приватность (`/setprivacy` → Disable), затем допишите id группы (отрицательное число) в `TELEGRAM_BOT_ALLOWED` и перезапустите бота: `sudo systemctl restart amnezia-tg-bot`.
* Служба: `sudo systemctl status amnezia-tg-bot`, лог: `/var/log/amnezia-tg-bot.log`.

## 🔄 Обновление компонентов

Обновляет скрипты и панель, не трогая конфиги, клиентов и SERVER-B:

```bash
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/daff4ik/amneziawg-cascade-v3/main/deploy.sh)" -- --update
```

Панель сама проверяет наличие новых коммитов в этом репозитории (кнопка «🔄 Обновления»).

## ⚙️ Управление через CLI (Консоль)

* **Добавление клиента:** `sudo amnezia-add-client.sh <имя>`
* **Удаление клиента:** `sudo amnezia-remove-client.sh <имя>`
* **Список клиентов и статистика:** `sudo amnezia-list-clients.sh`
* **Healthcheck туннеля:** `sudo amnezia-healthcheck.sh`
* **Настройка уведомлений Telegram:** `sudo amnezia-notify-setup.sh` *(или вкладка «🔔 Уведомления» в панели)*
* **Бэкап вручную:** `sudo amnezia-backup.sh`
* **Бэкап в облако:** `sudo amnezia-backup-cloud.sh` (off — отключить)
* **Обновление AmneziaWG:** `sudo amnezia-update-awg.sh`
* **Замена SERVER-B:** `sudo amnezia-restore-b.sh`
* **Протоколы:** `sudo amnezia-proto-<имя>.sh install|remove|status` (amnezia-dns, mtproxy, telemt)
* **Основной протокол:** `sudo amnezia-proto-amneziawg.sh status|update`
* **Конвертер конфига в vpn:// ссылку:** `sudo amnezia-vpn-link.py /root/clients/<имя>.conf "<имя сервера>"`
* **Временный доступ к панели по IP:8000 (при включённом Stealth):** `sudo amnezia-panel-access.sh on|off`
* **Отправить тестовое уведомление в Telegram:** `sudo amnezia-notify.sh "текст"`

Внутренние скрипты (вызываются системой, вручную обычно не нужны): `amnezia-server-install.sh` (ставит пакеты AmneziaWG, вызывается deploy.sh), `amnezia-traffic-collector.py` (сбор статистики трафика по cron), `amnezia-notify.sh` (отправка уведомлений из других скриптов).

## 📱 Клиентские приложения

* **AmneziaVPN** (рекомендуется) — импорт `.conf` и `vpn://`.
* **AmneziaWG** — классические `.conf` файлы.
* Для MTProxy/Telemt — любой клиент Telegram по ссылке `tg://proxy` / `t.me/proxy`.

> Стандартный WireGuard-клиент **не сможет** подключиться к AmneziaWG-интерфейсам (нет параметров обфускации Jc, S1, H1…).

## 🐛 Диагностика и FAQ

**Панель не запускается или недоступна:**
```bash
sudo systemctl status amnezia-panel
sudo journalctl -u amnezia-panel -n 30
```

**Клиент подключается, но интернета нет:** проверьте туннель `ping -c 3 10.10.10.1` с SERVER-A.

**Низкая скорость / зависания:** MTU клиента 1280 или ниже; MSS Clamping уже прописан установщиком.

**Telemt не стартует:** `sudo journalctl -u telemt -n 30` — чаще всего порт занят или недоступен маскировочный домен (смените: `TELEMT_DOMAIN=... sudo amnezia-proto-telemt.sh install`).
